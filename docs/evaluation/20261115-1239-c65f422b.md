P2 makes that walk the implementer's hand-over and makes its truth blocking. The walk is an output, not a rule: one DecisionMade per unit, `<unit>-walk`, holding three lists that must be true against the unit's own diff at head.
- **Branches:** each branch or refusal the diff adds, with the test that drives it. This list absorbs the empty, zero, absent or repeated arm from the both-arms rule, which now points at it.
- **Homes:** each rule, helper, fixture or test shape the diff adds, with the lookup run for an existing home and what came back.
- **Sentences:** each doc comment, handbook or README sentence the diff touches or makes false.

The adjudicator blocks on the walk's truth. A missing walk, or a branch it leaves out or pairs with a test that does not drive it, is a missing test. A Homes or Sentences line an upheld finding shows false is wrong code. The walk is never a reason to re-audit, and the check-in owes none.
